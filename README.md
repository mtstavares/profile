# Portfólio de Matheus Tavares

Este projeto foi criado para apresentar, em um único espaço profissional, a
trajetória de Matheus Tavares como Cybersecurity Analyst, com ênfase em Blue
Team, Incident Response e Security Engineering.

O portfólio conecta experiência em segurança defensiva, redes, infraestrutura,
automação e desenvolvimento de software. A proposta é tornar essa trajetória,
os projetos técnicos, as certificações e o currículo acessíveis para processos
seletivos, networking profissional e avaliação técnica.

A aplicação também funciona como um currículo web bilíngue, em português e
inglês, com páginas de projetos, cases técnicos, credenciais e versões do
currículo em PDF.

## Tecnologias utilizadas

- React 19 — construção da interface.
- TypeScript 6 — tipagem estática e organização do código.
- Vite 8 — desenvolvimento local e build de produção.
- Tailwind CSS 4 — tokens e utilitários de estilo.
- React Router 8 — rotas e navegação entre páginas.
- Framer Motion 13 — transições discretas com suporte a reduced motion.
- Lucide React — ícones da interface.
- Inter e IBM Plex Mono — tipografia local da aplicação.
- ESLint e Prettier — qualidade e padronização do código.
- Playwright — geração dos PDFs durante o build.
- GitHub Actions e GitHub Pages — publicação automatizada.
